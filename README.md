# Avoid — Dino Run-inspired rescue game

A browser-native 2D action-platformer prototype built with HTML5 Canvas, vanilla JavaScript ES modules, CSS3 and Vite.

The campaign follows Vasti and Blue as they work together to rescue Beta from poachers. Both dinosaurs remain present in every level; the player chooses which one to control.

## Development

- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Controls

- `A` / `D` or `←` / `→`: move
- `W`, `↑` or `Space`: jump
- `S` or `↓`: roar / attack (when available)
- `Esc`: pause
- `M`: mute audio

## Deployment

Deploy as a Vite static site on Vercel. Build command: `npm run build`; output directory: `dist`.

## Notes

This is an original fan-made implementation. It uses original Canvas-drawn placeholder artwork and generated Web Audio tones; no game assets, source code, sprites or audio are copied from Pixeljam, Universal, or other rights holders.

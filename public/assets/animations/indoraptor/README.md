# Indoraptor animation previews

Both source generations include transparent 8-frame looping GIF previews for `idle`, `walk`, `jump` and `eat`.

- `first-generation/`: black and gold reference.
- `second-generation/`: ivory and turquoise reference.

These GIFs are preview/export assets. In-game rendering uses the matching eight-part SVG rig so the tail, hind limbs, forelimbs, head and hinged jaw remain independently articulated.
